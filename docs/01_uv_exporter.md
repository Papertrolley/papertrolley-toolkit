# PT Scaled UV Exporter

Плагин назначает UUID вершинам и экспортирует UV-развёртку
в калиброванный PNG с маркерами всех вершин.

## Зачем

- **UUID** — стабильные ID вершин. Переживают сдвиг индексов
  при правках модели. Без них любая правка ломает разметку фото.
- **UV-PNG** — «шаблон» для будущей выкройки. С маркерами
  вершин превращается в точную карту для разметки в GIMP.

**Когда:** один раз для каждой модели, после [подготовки
модели](00_model_prep.md).

## Установка

1. `addons/PT_scaled_uv.zip` →
   `Edit → Preferences → Add-ons → Install...`
2. Включить галочку `PT Scaled UV`.
3. **Перезапустить Blender** (обязательно).
4. Панель: `N` в 3D Viewport → вкладка **PT Mapper** → **PT Scaled UV**.

## Пошагово

### 1. Назначить UUID

Выделить все mesh-объекты → **Assign Vertex UUIDs**.

Ожидаемый лог:
```
[PBA UVE] UUID: 2366 новых, 0 дубликатов, 0 без изменений. Объектов: 19
```

### 2. Проверить

**Check UUIDs**. Должно быть `нулей 0, дубликатов 0` у всех
объектов. Если есть проблемы — запустить Assign ещё раз
(он исправит).

### 3. Настроить

| Параметр | Значение |
|---|---|
| Scale | `1 : 87` |
| DPI | `600` |
| Margin | `5` мм |
| Gap | `10` мм |
| Wrap width | `0` (авто) |
| Min object | `30` px |
| Marker size | `2` px |
| Output Path | путь к `layout_uv.png` |

### 4. Экспортировать

Выделить все mesh → **Export UV Layout**.

Ожидаемый лог:
```
[PBA UVE] Экспортировано объектов: 19, пропущено: 0,
маркеров: 2366. Полотно: 6241×4535 px
```

Рядом создаётся `layout_uv.uv.json` — **не удалять**,
понадобится в Layout Mapper.

### 5. Проверить PNG в GIMP

- Чёрные контуры островов — не пересекаются.
- Пурпурные точки — по одной на каждую вершину
  (на швах — по несколько).
- Автобус 12 м в 1:87/600dpi занимает ~3150 px
  по длинной стороне.

## Настройки кратко

- **Scale** — знаменатель масштаба (87 для 1:87).
- **DPI** — 600 стандарт, менять не нужно.
- **Wrap width** — 0 = одна широкая строка; ненулевое =
  перенос объектов на новые строки.
- **Min object** — объекты меньше N px по обеим сторонам
  пропускаются (защита от мусора).
- **Debug labels** — рисует имена объектов на PNG
  (только для диагностики, выключить перед финальным
  экспортом).
- **Per-object PNGs** — отдельный PNG на каждый объект
  в подпапку `<output>_objects/`.
- **Marker size** — радиус пурпурных точек. 1 px если полотно
  плотное, 3–4 если нужно ловить мелкие детали.

## Частые проблемы

**Объект занимает всё UV-пространство** (например, крыша
3000×3000 вместо 3000×700).
→ В UV Editor выделить объект, `A → U → Pack Islands`.

**Полотно слишком широкое** (10000+ px).
→ Задать `Wrap width = 4960` или `Pack Islands` для
проблемных объектов.

**Мусорные острова в PNG.**
→ Экспортировать только нужные объекты (выделение) или
поднять `Min object` до 50–100.

**Маркеров не видно.**
→ Увеличить `Marker size` до 3–4. Проверить `Check UUIDs`.

**`UUID: 0 новых, 0 дубликатов` при непустой сцене.**
→ Атрибут существует, но пустой. В Python Console:

```python
import bpy
for obj in bpy.data.objects:
    if obj.type == 'MESH':
        attr = obj.data.attributes.get("pba_vertex_id")
        if attr and len(attr.data) == 0:
            obj.data.attributes.remove(attr)
            print(f"Удалён у {obj.name}")
```

Затем Assign UUIDs заново.

**`Экспортировано: 15, пропущено: 4`.**
→ Открыть System Console
(`Window → Toggle System Console`) — там построчный лог
причин пропуска: нет UV, слишком мелкий, пустая геометрия.

**`Полотно слишком большое: 45000×8000`.**
→ Проверить Scale (может, `1:8` вместо `1:87`) или DPI.
