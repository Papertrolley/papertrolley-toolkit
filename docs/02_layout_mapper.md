# PT Layout Mapper

Плагин связывает UV-острова 3D-модели с областями на выкройке.
Результат — JSON с гомографиями «выкройка ↔ UV», по которым
`transfer_blender.py` переносит текстуры.

## Зачем

Модель знает, какая точка поверхности где находится в UV.
Выкройка — плоский лист, на котором детали разложены
по-своему. Нужно связать эти два пространства: для каждой
детали выкройки указать, какому UV-острову она соответствует.

Плагин делает это через 4 опорные точки: на 3D-модели
и на выкройке. По ним строится гомография (преобразование
плоскости в плоскость), которая потом применяется к каждому
пикселю.

**Когда:** когда выкройка-шаблон нарисована в GIMP.

## Установка

1. `addons/PT_layout_mapper.zip` →
   `Edit → Preferences → Add-ons → Install...`
2. Включить `PT Layout Mapper`.
3. **Перезапустить Blender.**
4. Панель: `N` → вкладка **PT Mapper** → **PT Layout**.

## Два режима

Плагин работает в двух режимах, переключаются в панели
сверху:

- **Quad** — 4 произвольные вершины модели. Используется
  для мелких деталей и «доводки» поверх островов.
- **Island** — целый UV-остров. Основной режим, для большинства
  деталей выкройки.

**Приоритет:** острова обрабатываются первыми, квады —
поверх них. Если квад и остров пересекаются, квад «победит»
(его текстура перезапишет островную).

## Пошагово (Island)

### 1. Загрузить выкройку

**Layout Path** — путь к PNG выкройки (сделанному в GIMP).
**Load Layout** — создаёт плоскость с текстурой позади модели.

**Frame Layout View** — переключает вид на фронтальный
ортоскопический и включает Material Preview. Так вы видите
и модель, и выкройку одновременно.

### 2. Захватить UV-остров

1. В 3D Viewport выделить **одну грань** одного UV-острова.
   В Edit Mode горячая клавиша **3** → выделить грань.
   Вернуться к выделению вершин - горячая клавиша **1**.
2. В панели **Start Island**.
3. В логе: `Остров: N граней. UV bbox (u1,v1)-(u2,v2)`.

**Проверка:** UV bbox острова должен занимать **не более 50%**
по каждой оси. Если больше — BFS склеил несколько островов.
Перевыделите грани точнее.

### 3. Отметить 4 вершины острова

**Pick 4 Island Vertices** — модальный режим. Курсор над
моделью, кликаете 4 вершины **в определённом порядке**
(например, верхний-левый → верхний-правый → нижний-правый →
нижний-левый). Порядок запоминается, его надо будет
повторить на выкройке.

После каждого клика статус: `Вершина N: v123, 2 UV-варианта`.

### 4. Отметить 4 точки на выкройке

**Pick 4 Layout Points** — модальный режим. Курсор над
плоскостью выкройки, кликаете 4 угла **в том же порядке**.

Клики автоматически снапятся к ближайшему:
- **пурпурному маркеру** (приоритет), если он в радиусе
  `snap_radius`;
- **чёрной линии** выкройки, если маркера нет.

В статусе: `Точка N: (x, y) (маркер)` или `(линия)`.

### 5. Commit Island

**Commit Island** — фиксирует остров. В логе:
```
[PBA LM] Остров i_001 добавлен
```

### 6. Повторить для всех островов

У каждого UV-острова (детали модели, которая пойдёт в
выкройку) — свой цикл Start → Pick Vertices → Pick Points →
Commit.

### 7. Экспорт

**Export JSON** — сохраняет все острова и квады в один
`*.quads.json`. Рядом — `*.png` с выкройкой (для background
в transfer_blender.py).

**Автосинхронизация:** при экспорте `x_world` всех углов
обновляется из актуальных позиций вершин. Если модель
менялась после разметки — данные будут правильными.

## Пошагово (Quad)

То же, что Island, но:
- **Capture 4 3D Vertices** — выделяете 4 вершины в Edit
  Mode, кликаете кнопку (без модального режима);
- произвольные вершины, не обязательно один остров;
- полезно для мелких деталей, где UV-остров делить неудобно.

## Дополнительные инструменты

### Snap

Клики по выкройке снапятся к ближайшему:
- **маркеру** (`#FF00FF`) — идеально, точность 0.5 px;
- **линии** — центр тёмной линии в окрестности клика;
- **клик как есть** — если ничего рядом.

Настройки в секции Snap:
- `snap_to_lines` — включить/выключить;
- `snap_radius_px` — радиус поиска (по умолчанию 15);
- `snap_threshold` — порог яркости линии (180 для чёрных
  линий на белом фоне);
- `snap_marker_tolerance` — допуск цвета маркера (0.3 по
  умолчанию).

### Визуализация

Клик по острову/кваду в списке — на выкройке появляются
4 крестика (R, G, B, Y), на модели — 4 октаэдра тех же
цветов. Если цвета на модели и выкройке совпадают —
порядок углов правильный. Если нет — используйте `↻ / ⇄`.

### Повороты и отражения

Рядом с каждым островом/квадом:
- **↺ / ↻** — сдвигает порядок 2D-кликов на 1 позицию.
- **⇄** — обратный порядок (исправить зеркало).

**Когда использовать:** если текстура переносится
зеркально или повёрнута на 90/180°. Это не меняет
3D-вершины, только порядок соответствия.

### Дублирование

**Duplicate** — создаёт копию острова/квада с теми же
3D-вершинами/UV, но с обнулёнными точками на выкройке.
Полезно, когда одна деталь повторяется дважды (левая
и правая дверь, две фары).

После Duplicate: кликните 4 новые точки на выкройке
для копии → Commit.

### Сортировка

**Sort** — автосортировка: сначала по имени объекта,
потом по положению верхнего-левого угла (сверху вниз,
слева направо).

**Порядок обработки в transfer_blender.py** — сверху вниз
по списку. Острова **перезаписывают** друг друга. Если
деталь должна быть поверх — переместите её **вниз** в
списке.

### Ручная перестановка

- **↑ / ↓** — сдвинуть остров/квад на позицию.
- Нужно, когда автосортировка не устраивает (например,
  мелкая деталь должна перекрыть крупную).

### Sync Coords

Кнопка **Sync Coords** — обновляет `x_world` всех углов
по текущему положению вершин в модели. **Обязательно**
после правок модели (Move, Snap, Nudge).

**Автоматически вызывается при Export JSON.** Кнопка
нужна только для ручного обновления (например, проверить
до экспорта).

### Импорт

**Import JSON** — загружает существующий `*.quads.json`.
При загрузке индексы вершин пересчитываются по UUID.

## Настройки кратко

| Параметр | Значение | Смысл |
|---|---|---|
| Layout Path | путь | PNG выкройки |
| Plane Width / Offset | 20 / 15 м | Размер плоскости за моделью |
| Mode | Island / Quad | Режим разметки |
| pending_part | строка | Метка детали (опционально) |
| snap_to_lines | вкл | Snap к маркерам/линиям |
| snap_radius_px | 15 | Радиус поиска |
| snap_threshold | 180 | Порог линии |
| snap_marker_tolerance | 0.3 | Допуск маркера |
| highlight_size | 0.10 м | Размер маркеров визуализации |

## Частые проблемы

**`гомография вырождена`.**

4 точки лежат на одной прямой, совпадают или почти
совпали. Переразметить: в списке удалить остров (X),
разметить заново с более разнесёнными углами.

**`остров не найден в BFS`.**

UV-координаты в JSON не совпадают с текущей
UV-развёрткой модели. Причина: UV unwrap был переделан
после разметки. **Переразметить** остров.

**`вершина не принадлежит острову`.**

Разметить вершину или весь остров заново, используя другие вершины.

**Дыры в текстуре по краям деталей.**

Причина: `--expand 1` не включен в transfer_blender.py.
См. [04 Transfer](04_transfer.md).

**Острова в списке, но при transfer'e пустые.**

Их UV не находится в BFS. Переразметить. Проверить,
что UV-развёртка модели не менялась после разметки.

## Порядок работы

1. Закрыть разметку фото (все JSON-ы готовы).
2. Открыть Layout Mapper, загрузить выкройку.
3. Разметить все острова (Island).
4. Продублировать повторяющиеся детали.
5. Разметить квады для мелких элементов (если нужно).
6. **Sync Coords** (если модель правили).
7. **Export JSON** — сохранить.
8. Запустить `transfer_blender.py`.
