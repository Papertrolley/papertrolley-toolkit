# transfer_blender.py

Утилита, которая собирает итоговую текстуру. Для каждого
пикселя выкройки находит соответствующую точку на 3D-модели
и берёт цвет с фотографии, где эта точка видна лучше всего.

## Зачем

Все предыдущие шаги подготовили данные:
- UV-развёртка с UUID;
- позы камер для всех фото (`*.vertices.json`);
- соответствие «UV-остров ↔ область выкройки» (`*.quads.json`).

Осталось собрать это вместе — заполнить выкройку
реальными текстурами с фотографий.

## Запуск

Утилита работает в фоне Blender (не в системном Python).
Запуск:

```bash
blender --background model.blend --python transfer_blender.py -- \
    --layout layout.quads.json \
    --photo DSC_2505.jpg --photo-meta DSC_2505.vertices.json \
    --photo DSC_2508.jpg --photo-meta DSC_2508.vertices.json \
    --photo DSC_2512.jpg --photo-meta DSC_2512.vertices.json \
    --out result.png \
    --bg layout \
    --expand 1 \
    --verbose
```

## Параметры

| Параметр | Обязательный | Описание |
|---|---|---|
| `--layout` | да | JSON от Layout Mapper |
| `--photo` | да | Путь к фото (можно повторять) |
| `--photo-meta` | да | JSON от Vertex Mapper (по одному на фото) |
| `--out` | да | Путь к итоговому PNG |
| `--bg` | нет | `layout` (наложить на выкройку) или `transparent` (только текстура) |
| `--expand` | нет | Расширение островов на N px (по умолчанию 0) |
| `--blend-n` | нет | Сколько фото смешивать (1 = без смешивания, 3 = по умолчанию) |
| `--blend-power` | нет | Степень cos в весах (2.0 по умолчанию) |
| `--verbose` | нет | Подробный лог по островам |

## Что делает

### Шаг 1. Острова

Для каждого UV-острова из `layout.quads.json`:

1. Строит гомографию `layout_px → UV` по 4 углам.
2. Ищет UV-остров в меше (BFS по UV-связности).
3. Для каждого пикселя внутри bbox острова:
   - переводит в UV через гомографию;
   - находит треугольник меша, в котором лежит UV;
   - интерполирует 3D-точку.
4. Для каждой 3D-точки среди всех фото выбирает лучшее:
   - **в кадре**;
   - **не окклюзировано** (depth buffer);
   - **cos > порога** (поверхность не отвёрнута).
5. Берёт цвет с выбранного фото (билинейная интерполяция).

### Шаг 2. Квады

То же, но:
- 3D-точки берутся из `corners_3d` (4 конкретные вершины);
- гомография строится «фото → layout», а не «layout → UV»;
- квады **перезаписывают** области, уже заполненные островами.

### Шаг 3. Расширение (если `--expand > 0`)

После всех островов расширяет их на N пикселей в 8
направлений. Пишется **только в пустые пиксели** —
не перезаписывает соседние острова.

**Зачем:** закрывает щели между деталями на выкройке,
появившиеся из-за погрешности гомографии.

## Настройки подробно

### `--bg`

- **`layout`** — итоговый PNG накладывается на выкройку
  (с клапанами, линиями сгиба, номерами). Готово к печати.
- **`transparent`** — только текстуры на прозрачном фоне.
  Для композитной сборки в GIMP.

### `--expand`

| Значение | Когда использовать |
|---|---|
| `0` | Не нужно расширение (нет щелей) |
| `1` | **По умолчанию** — закрывает большинство щелей |
| `2–3` | Если после `1` щели остались |

**Осторожно:** `--expand > 3` может «съесть» соседние
мелкие детали.

### `--blend-n`

| Значение | Поведение |
|---|---|
| `1` | Жёсткий выбор одного фото. Резкие стыки. |
| `3` | Смешивание 3 лучших фото. **Рекомендуется.** |
| `5` | Максимально плавные переходы, риск «призраков». |

**Смешивание полезно**, когда несколько фото видят
поверхность под близкими углами. Если угол
разный — смешивание может испортить.

### `--blend-power`

Степень cos в весах смешивания.
- `1.0` — мягкое смешивание (все фото вносят вклад).
- `2.0` — стандарт.
- `4.0` — жёсткое, почти как `--blend-n 1`.

## Частые проблемы

### Дыры в текстуре на видимых деталях

**Симптом:** `Right_side` покрыт на 15%, хотя виден целиком.

**Причина:** сломан depth buffer или неправильные нормали.

**Решение:**
1. Откройте `result.png` — где дыры.
2. Если дыры на всех фото — проверить `--verbose` лог,
   что depth buffer строится (там строки `depth buffer готов`).
3. Если depth OK, но дыры — прогнать в Blender
   `Shift+N` (нормали), переэкспортировать `.blend`.

### Текстура «налезает» с неправильной стороны

**Симптом:** на левом борту видна текстура с правого.

**Причина:** проверка окклюзии не работает (например,
depth buffer пустой).

**Решение:**
1. Смотреть `--verbose`: сколько пикселей покрыто для
   `Left_side` (должно быть 0, если правая камера).
2. Если >0 — проверить в Blender, что модель замкнута
   (нет дыр), нормали смотрят наружу.

### Резкие стыки между зонами разных фото

**Симптом:** на панели видна чёткая вертикальная граница.

**Причина:** `--blend-n 1`, два фото с разной экспозицией.

**Решение:**
1. Увеличить `--blend-n` до 3.
2. Уменьшить `--blend-power` до 1.5 (мягче).
3. Если не помогает — разные фото сняты в разное время,
   нормализуйте яркость в GIMP перед сборкой.

### Щели между деталями на выкройке

**Симптом:** между колесом и аркой — белая полоса 1–2 px.

**Причина:** гомография острова даёт ±1 px ошибки, соседние
острова не совпадают на границе.

**Решение:** `--expand 1` (или 2, если 1 не хватило).

### `не найдено фото` для квада

**Симптом:** `q_005: не выбрано фото` в логе.

**Причина:** все 4 угла окклюзированы со всех фото
(например, квад на задней стенке, а фото только спереди).

**Решение:** добавить фото с нужного ракурса. Или
проверить, что углы квада правильно размечены.

### Остров обработан, но пустой на PNG

**Симптом:** в логе `i_XXX: покрыто 50000 / 50000`, но
на PNG в этой области — дыра.

**Причина:** все точки попали в окклюзию, но проверка
не справилась с «пограничным» случаем.

**Решение:** перезапустить с `--verbose`, посмотреть
распределение. Если все пиксели ушли на одно фото, но
визуально не совпадает — пересмотреть нормали.

## Оптимизация скорости

- **Depth buffer** — самый тяжёлый шаг. ~5–10 сек на фото
  при 10k треугольников.
- **Острова** — ~10–30 сек на крупный остров.
- **Квады** — быстрые, обычно <1 сек.
- **Полный прогон** (20 островов, 3 фото) — 3–5 минут.

Если медленно:
1. Уменьшить `--blend-n` до 1.
2. Сократить число фото до минимума.
3. Разбить работу: сначала острова, потом квады (два
   прогона, второй — только с quads в layout).

## Что делать с результатом

`result.png` — это готовая текстура для печати. Дальше:

1. **Открыть в GIMP** поверх выкройки.
2. **Проверить:** стыки, пропуски, цветопередачу.
3. **Дорисовать вручную:** мелкие дефекты, инпейнтинг
   дыр (если они есть).
4. **Добавить клапаны, линии сгиба, номера** (если не
   сделано раньше).
5. **Печать на A4 @ 600 dpi.**
6. **Сборка.**
