# Подготовка модели

Первый и самый важный шаг. Если модель подготовлена
неправильно, дальше всё разваливается непредсказуемо:
камеры не калибруются, острова не находятся, текстуры
съезжают. Поэтому — не спешите.

## Что должно быть в итоге

После этого документа вы получите:

- Чистую модель без дубликатов вершин и перевёрнутых нормалей.
- UV-развёртку, где каждая деталь — отдельный остров.
- Назначенные UUID на каждой вершине (уникальные ID,
  которые переживут правки топологии).
- Понимание, какие объекты соответствуют каким деталям
  выкройки.

## Шаг 1. Исходная модель

У вас есть модель автобуса, сделанная в Blender, CAD-системе
или полученная из другого источника. Неважно, откуда она —
важно, что перед началом работы она соответствует
требованиям ниже.

### Требования к модели

- **Геометрия финальная.** Никаких «потом доделаю крышу» —
  после назначения UUID топологию трогать нельзя.
- **Все части разделены по объектам.** Если сейчас вся модель
  — один большой меш, разделите его. Каждая деталь будущей
  выкройки должна быть отдельным объектом. Пример:
  не «кузов», а «Right_side», «Left_side», «Roof_side»,
  «Front_side», «Back_side», «Wheels_front_left» и т.д.
- **Имена осмысленные.** Они попадут в JSON и в OBJ-экспорт.
  `Cube.001` — плохое имя. `Wheels_back_right` — хорошее.
- **Размеры в метрах.** Стандарт Blender. Автобус ~12 м
  в длину — значит, `location.x` разброс от −6 до +6.

## Шаг 2. Чистка геометрии

Перед UV-развёрткой и назначением UUID нужно убрать
типичный мусор.

### 2.1. Сварка дубликатов вершин

Дубликаты — вершины, лежащие в одной точке, но не связанные
между собой. Они появляются после импорта из CAD, Boolean,
ручного моделирования.

1. Выделите все mesh-объекты (`Ctrl+A` в 3D Viewport).
2. `Tab` → Edit Mode.
3. `A` → выделить всё.
4. `M` → **By Distance**.
5. Внизу появится сообщение вида `Removed N vertice(s)`.
   Если N > 0 — дубликаты были, теперь их нет.

> **Важно:** сварка **до** назначения UUID. Если сделать
> после — UUID удалённых вершин потеряются, и вся разметка
> поедет.

### 2.2. Удаление loose-геометрии

Loose-вершины и рёбра не принадлежат ни одной грани.
В UV-развёртку они не попадают, в OBJ-экспорт тоже.
Если они используются в разметке фото — возникнут проблемы.

1. `Tab` → Edit Mode.
2. `A` → выделить всё.
3. `Select → Select All by Trait → Loose Geometry`.
4. `X` → **Vertices** (или Edges, если вершины не выделились).

После этого `len(obj.data.vertices)` должен совпадать
с реальным числом вершин в гранях.

**Как проверить:**
```python
import bpy
for obj in bpy.data.objects:
    if obj.type != 'MESH':
        continue
    me = obj.data
    used = set()
    for poly in me.polygons:
        for vi in poly.vertices:
            used.add(vi)
    loose = [i for i in range(len(me.vertices)) if i not in used]
    if loose:
        print(f"{obj.name}: loose {loose}")
```

Если вывод пустой — всё чисто.

## Шаг 3. Нормали

Перевёрнутые нормали ломают выбор ракурса в transfer'е
(пиксели берутся с фото, которое смотрит на изнанку).

1. Выделите все mesh-объекты.
2. `Tab` → Edit Mode.
3. `A` → выделить всё.
4. `Shift+N` → **Recalculate Outside**.

### Проверка

1. В 3D Viewport откройте **Overlays** (стрелка вниз
   справа сверху).
2. Включите **Face Orientation**.
3. Все грани должны быть **синие** (снаружи).
4. Если видите **красные** пятна — там нормали смотрят
   внутрь. Выделите эти грани вручную и `Alt+N` → **Flip**.

> **Зачем это:** если пропустить, transfer_blender.py
> возьмёт текстуры с неправильных фото для этих граней.
> Дыр в текстуре не будет, но цвета будут не те.

## Шаг 4. UV-развёртка

Каждый объект разворачивается **отдельно**. Это критически
важно: если выделить несколько объектов и развернуть вместе,
Blender смешает их в одном UV-пространстве, и острова
наложатся.

### 4.1. Разметка швов

Швы — рёбра, по которым модель «разрезается» на остров.
Правило простое: **шов идёт по границе детали выкройки**.

Для автобуса:
- верхний край борта (стык с крышей);
- нижний край борта (стык с днищем);
- передняя и задняя вертикаль (стык с мордой/кормой);
- вокруг арок колёс;
- вокруг дверных проёмов;
- по стыкам панелей, если они на самом деле разные.

1. `Tab` → Edit Mode.
2. Выделите нужные рёбра.
3. `Ctrl+E` → **Mark Seam**. Рёбра станут красными.

### 4.2. Unwrap

1. Выделите грани одного объекта (`A` после выбора объекта).
2. `U` → **Unwrap**.

Если результат «мятый» — попробуйте:
- `U` → **Follow Active Quads** (для квадовой сетки);
- `U` → **Smart UV Project** (быстрый, но менее контролируемый);
- добавить ещё швов и `Unwrap` заново.

### 4.3. Pack Islands

1. В UV Editor: `A` → выделить всё.
2. `U` → **Pack Islands**.
3. Blender аккуратно разложит острова в `[0,1]×[0,1]`.

### 4.4. Проверка размера

Откройте **UV Editor**. Каждый остров должен:

- занимать разумную часть `[0,1]×[0,1]`;
- не пересекаться с другими островами;
- иметь пропорции, похожие на пропорции детали.

Если остров занимает >50% — это подозрительно. Скорее всего,
BFS в Layout Mapper потом склеит его с чем-то ещё.
Разбейте швами на части.

### 4.5. Повтор для каждого объекта

Закройте Edit Mode. Выделите следующий объект.
Повторите шаги 4.2–4.4.

> **Не выделяйте сразу несколько объектов!** Даже если хочется
> ускорить. Каждый — отдельно, `Pack Islands` — отдельно.

## Шаг 5. Назначение UUID

UUID — уникальные идентификаторы вершин. Они переживают
сдвиг индексов, слияние объектов и правки геометрии
(без изменения топологии).

1. Откройте панель `PBA UV Exporter`
   (`N` в 3D Viewport → вкладка **PBA UV Exporter**).
2. Выделите **все** mesh-объекты модели.
3. Нажмите **Assign Vertex UUIDs**.

Ожидаемый результат в консоли:
```
[PBA UVE] UUID: 2366 новых, 0 дубликатов, 0 без изменений.
Объектов: 19
```

### Проверка

Нажмите **Check UUIDs** в той же панели. Ожидаемый лог:
```
[PBA UVE] Проверка UUID для 19 объектов:
  Right_side: 143 вершин, UUID 143, нулей 0 → OK
  Roof_side: 96 вершин, UUID 96, нулей 0 → OK
  ...
[PBA UVE] Итого: 2366 вершин, с UUID 2366, без UUID 0
```

Если увидите `нулей: N > 0` или `дубликатов: N > 0` — запустите
**Assign Vertex UUIDs** ещё раз. Оператор исправит: нулям
назначит свежие ID, дубликатам тоже.

## Шаг 6. Экспорт UV с маркерами

Это нужно для того, чтобы потом на выкройке было видно, где
какая вершина модели.

1. В панели **PBA UV Exporter**:
   - **Scale**: `1 : 87` (или ваш масштаб);
   - **DPI**: `600`;
   - **Margin**: 5 мм;
   - **Marker size**: 2 px;
   - **Marker color**: пурпурный (по умолчанию).
2. **Output Path**: путь к PNG, например
   `projects/liaZ/layout_uv.png`.
3. Нажмите **Export UV Layout**.

Ожидаемый результат:
```
[PBA UVE] Экспортировано объектов: 19, пропущено: 0,
маркеров: 2366. Полотно: 6241×4535 px
```

Рядом с PNG создаётся `layout_uv.uv.json` — метаданные.
Не трогайте его, он понадобится в Layout Mapper.

### Проверка

Откройте PNG в GIMP. Должны увидеть:
- чёрные контуры UV-островов на белом фоне;
- мелкие пурпурные точки — маркеры всех вершин;
- острова не наложены друг на друга.

Если маркеры слишком плотные — уменьшите `Marker size` до 1.

## Чек-лист перед переходом

- [ ] Все дубликаты вершин сварены (`Merge by Distance`).
- [ ] Loose-вершины удалены.
- [ ] Нормали пересчитаны (`Shift+N`), все грани синие
      в Face Orientation.
- [ ] UV unwrap каждого объекта — отдельно.
- [ ] Pack Islands каждого объекта — отдельно.
- [ ] Все острова в `[0,1]×[0,1]`, не пересекаются.
- [ ] UUID назначены, Check UUIDs показывает 0 нулей
      и 0 дубликатов.
- [ ] UV PNG экспортирован с маркерами.
- [ ] `layout_uv.uv.json` лежит рядом с PNG.

Если все пункты отмечены — модель готова, ошибок на
следующих шагах будет минимум.

## Типичные ошибки

### «Merge by Distance стёр лишнее»

Порог по умолчанию 0.0001. Если после сварки пропали
нужные вершины — `Ctrl+Z`, потом `M → By Distance`
с меньшим порогом (0.001 или 0.0001).

### «Unwrap даёт странный результат»

Скорее всего, швов мало. Добавьте ещё. Или попробуйте
`Follow Active Quads` — работает идеально на квадовых сетках.

### «Pack Islands раскидал острова по всему полю»

Это нормально — Blender старается минимизировать пустоты
между островами. Пока все внутри `[0,1]` — всё в порядке.

### «UUID назначились, но потом пропали»

Скорее всего, вы после этого применили Subdivide или другой
модификатор топологии. UUID сохраняются, но у новых вершин
их нет. Запустите **Assign Vertex UUIDs** ещё раз —
он назначит ID новым вершинам.
