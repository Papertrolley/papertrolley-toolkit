# PaperTrolley Toolkit

Набор инструментов для создания бумажных моделей транспорта
с реалистичными текстурами, снятыми с реальных фотографий.

## Что это

Проект решает одну задачу: **перенести текстуры с фотографий
на плоскую выкройку бумажной модели**.

Традиционный путь — нарисовать выкройку, затем вручную
подгонять каждую панель фотографии под каждую деталь. На автобус
это часы работы и вероятные ошибки.

Наш путь — использовать низкополигональную 3D-модель как
посредника. Модель знает, какая точка поверхности какой точке
на фото соответствует. Дальше это переносится на выкройку
автоматически.

## Как устроен пайплайн

```
┌────────────────────────┐  Получение 2D-развёртки из 3D-модели (1 раз).
│ 1. Scaled UV Exporter  │  Экспортирует UV-развёртку
│    (Blender)           │  Назначает UUID вершинам,
└────────────────────────┘  с маркерами и калибровкой.
        │                   
        ▼
┌────────────────────────┐  Разметка листов выкройки (1 раз).
│ 2. Layout Mapper       │  Cвязывает развёрнутые UV-острова
│    (Blender)           │  3D-модели с размеченными областями
└────────────────────────┘  на выкройке.
        │
        ▼
┌────────────────────────┐  Разметка фото (много раз).
│ 3. Photo Mapper        │  Расстановка опорных точек 3D-модели
│    (Blender)           │  на фото и восстановление кадра.
└────────────────────────┘  Сохраняет JSON с позой камеры.
        │
        ▼
┌────────────────────────┐  Экстрактор текстур с фотографий (много раз).
│ 4. transfer_blender.py │  Консольная утилита. Запускает в фоне Blender.
│    (утилита)           │  Для каждого пикселя выкройки находит
└────────────────────────┘  соответствие на размеченных фотографиях.
        │
        ▼
┌────────────────────────┐  Ручная доводка.
│ 5. GIMP + печать       │  Финальная доводка, клапаны,
└────────────────────────┘  линии сгиба, сборка.
```

Дополнительно есть:
- **PBA Triangulation** — вспомогательный инструмент для
  уточнения 3D-модели по нескольким фото.
- **bake_layout_to_uv.py** — обратный перенос текстуры
  с выкройки на модель (для визуальной проверки).

## Требования

- **Blender 4.0 или новее.** Раньше не работает из-за
  особенностей API атрибутов.
- **Python 3.10+** (входит в Blender).
- **Pillow (PIL)** и **NumPy** — обычно идут в комплекте
  с Blender. Проверить: откройте Python Console в Blender
  и выполните `import PIL, numpy; print("ok")`.
- **GIMP** или аналогичный редактор для работы с выкройкой.

## Установка плагинов

Четыре плагина — четыре ZIP-архива. Установка одинаковая:

1. В Blender: `Edit → Preferences → Add-ons → Install...`
2. Выбрать ZIP-архив.
3. Включить галочку рядом с названием аддона.
4. Перезапустить Blender (обязательно — правки в
   PropertyGroup подхватываются только при перезапуске).

Плагины:
- `PT_scaled_uv.zip`
- `PT_layout_mapper.zip`
- `PT_photo_mapper.zip`
- `PT_triangulation.zip` (опционально)

Все четыре можно включить одновременно. Они не конфликтуют.

Утилиты `transfer_blender.py` и `bake_layout_to_uv.py` —
это отдельные `.py`-файлы, ничего устанавливать не нужно.
Кладутся в папку проекта.

## Быстрый старт

Полный цикл для одного автобуса. Детали — в отдельных документах.

```
[Подготовка модели]
1. Merge by Distance, Shift+N на модели
2. UV unwrap каждого объекта отдельно, Pack Islands
3. Assign UUIDs (UV Exporter)

[Выкройка]
4. В GIMP: открыть UV-PNG с маркерами, обвести,
   добавить клапаны и линии сгиба → сохранить как PNG
5. Layout Mapper: загрузить выкройку, разметить
   UV-острова → Export JSON

[Фото]
6. Для каждого фото: Vertex Mapper → 6+ пар → Save
   (получаем *.vertices.json рядом с каждым фото)

[Сборка текстуры]
7. blender --background model.blend --python pt_automaton.py
   с флагами --layout, --uv-json, --photo (одно или несколько) → result.png
8. В GIMP: финальная доработка, печать, сборка
```

## Железные правила

Десять вещей, которые предотвращают 90% проблем. Нарушение
любого из них — часы отладки.

1. **Модель перед стартом финальная.** Топология не меняется
   после назначения UUID.
2. **UV unwrap каждого объекта отдельно.** Не выделять
   несколько объектов и разворачивать вместе.
3. **Assign UUIDs — один раз в самом начале.**
4. **После Assign UUIDs топологию не менять.** Никаких
   Subdivide, Extrude, Boolean.
5. **Vertex Mapper: минимум 6 пар на фото.** Меньше —
   нестабильное решение.
6. **Фото может быть кропнутым.** Плагин сам разберётся
   с нативным разрешением.
7. **После правок модели — Sync Coords в Layout Mapper**
   и заново Export JSON.
8. **Если остров занимает >50% UV-пространства** — BFS,
   возможно, склеил несколько. Выделяйте грани точнее.
9. **pt_automaton.py запускается через `blender --background`**
   с флагом `--verbose`. Не через системный Python.
10. **Минимум 3 фото с разных ракурсов** для хорошего
    покрытия текстуры.
